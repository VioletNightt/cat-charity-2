QRKot — Фонд поддержки котиков 🐱
QRKot — это благотворительный сервис, который собирает пожертвования на различные проекты помощи кошкам. В фонде можно создавать целевые сборы («проекты») с конкретной суммой, а пожертвования автоматически распределяются между открытыми проектами по принципу «первый открытый — первый на получает средства».

Проект реализован на FastAPI с асинхронной работой с базой данных, использует SQLAlchemy (ORM) и Alembic для миграций. Код написан в соответствии с лучшими практиками: разделение на слои (модели, схемы, сервисы, API), использование DI, валидация через Pydantic.

Основные возможности
Управление проектами
Создание, просмотр, редактирование и удаление целевых сборов.

Каждый проект имеет название, описание и целевую сумму.

После достижения суммы проект автоматически закрывается.

Пожертвования
Любой пользователь может сделать пожертвование (сумма > 0) с опциональным комментарием.
Пожертвование не привязывается к конкретному проекту — средства распределяются автоматически.

Автоматическое инвестирование
При создании нового пожертвования или нового проекта запускается алгоритм распределения:

Неиспользованные остатки пожертвований направляются в самый старый открытый проект.

Если пожертвование покрывает текущий проект, остаток переходит к следующему по очереди.

Если все проекты закрыты, средства ожидают появления нового проекта.

Валидация данных

Название проекта: от 5 до 100 символов, уникально.

Описание: не менее 10 символов.

Суммы: целые положительные числа.

Запрещено изменение/удаление закрытых проектов, а также удаление проектов с уже внесёнными инвестициями.

Документация Swagger/ReDoc автоматически генерируется и доступна по адресам /docs и /redoc.

Технологии
Python 3.10+

Установка и запуск
1. Клонирование репозитория
bash
git clone https://github.com/VioletNightt/qrkot.git
cd qrkot
2. Создание и активация виртуального окружения
bash
python -m venv venv
source venv/bin/activate   # для Linux/macOS
venv\Scripts\activate      # для Windows
3. Установка зависимостей
bash
pip install -r requirements.txt
4. Настройка переменных окружения
Создайте файл .env в корне проекта (можно скопировать из .env.example):

text
DATABASE_URL=sqlite+aiosqlite:///./fastapi.db
Для PostgreSQL замените на postgresql+asyncpg://user:pass@localhost/dbname.

5. Применение миграций
bash
alembic upgrade head
6. Запуск приложения
bash
uvicorn app.main:app --reload
Приложение будет доступно по адресу http://127.0.0.1:8000.

Документация API
После запуска перейдите по ссылкам:

Swagger UI: http://127.0.0.1:8000/docs

ReDoc: http://127.0.0.1:8000/redoc

Основные эндпоинты:

Метод	Путь	Описание
GET	/charity_project/	Получить список всех проектов
POST	/charity_project/	Создать новый проект
PATCH	/charity_project/{id}	Обновить проект
DELETE	/charity_project/{id}	Удалить проект
GET	/donation/	Получить список всех пожертвований
POST	/donation/	Сделать пожертвование
Все эндпоинты возвращают данные в формате JSON.
